This page renders through `Layout.article` from the Phase 92 BrandKit
layout library — skip link, landmarks, and `bk-*` class hooks come from
the shell; the markdown body lands in the `Body` slot via
`NarrativeLayout.renderBody`. Style it by defining the `--bk-*` CSS
custom properties in `/brand.css`.
