# The retrieval pipeline's trace marks (RetrievalTrace.Stages).
#
# `mark` lines enumerate every mark the default RetrievalPipeline can emit,
# with <placeholders> for the parts that carry a value. They were gathered
# from SparseIndexCompositionTests.fs and docs/rag/api-reference.md, and
# RetrievalStage.mark renders exactly this set.
#
# `<composition>: <marks>` lines are the full mark sequence one request
# produces in that composition (SparseIndexCompositionTests.markScenarios).
# A change that moves one of them changes what every trace reader sees.
